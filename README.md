# ERP Redesign Dashboard Concepts

Dashboard concepts built with HTML, CSS, and JavaScript.

- **Example 1:** Light glassmorphism CRM dashboard with PDF export
- **Example 2:** Green sales administration dashboard with PDF export
- **Example 3:** Fashion analytics dashboard with accessible dark/light themes, monthly sales, stock alerts, and production metrics
- **Example 4:** Green fashion ERP dashboard with sales analytics, category mix, production overview, and PDF printing
- **Example 5:** Atelier fashion operations dashboard based on the supplied reference, with sales and stock metrics, collection management, production readiness, JSON import, and a sample room timer

- **Example 6:** AI-BL health dashboard recreated from the supplied reference, with lime accents, tracker charts, activity checklist, and breathing timer
- **Example 2 Clone:** Exact copy of Example 2 in `example-2-clone`, ready for separate customization

- **Example 7:** Vault inventory dashboard with product management, tag filters, stock charts, restock review, and responsive navigation

- **Example 8:** Fashion sales admin dashboard with forest-green navigation, monthly reporting, collection mix, product creation, and responsive mobile navigation

Open any example's `index.html` directly in a browser, including `example-5/index.html`. Example 5 uses in-memory demo data; additions reset on reload.

- **Example 10:** DK Studio fashion ERP overview, following `FASHION_ERP_DESIGN.md`: faint-blue sidebar, Manrope typography, sky-blue sales reporting, order management drawers, and production progress. Open `example-10/index.html`.

- **Example 11:** Fashion finance dashboard following `FASHION_ERP_DESIGN.md`, with cash-flow comparisons, expense allocation, transactions, collection targets, payment recording, and CSV export. Open `example-11/index.html`.

- **Example 12:** FinSet personal finance dashboard styled directly from the purple reference, independently of the ERP design guide. Includes grouped cash-flow bars, budget breakdown, saving goals, transaction filters, widget controls, responsive navigation, and light/dark themes. Open `example-12/index.html`. Uses illustrative USD data; widget visibility resets on reload.

  Its reusable components, shared tokens, preserved visual exceptions, and regression checks are documented in [the Example 12 design system](example-12/design-system/README.md).

- **Example 12 Copy:** FinSet dashboard with Siohioma's fashion CRM sidebar from Example 2 Clone Home, including collapsible navigation, section tooltips, and mobile navigation. Open `example-12 copy/index.html`.
