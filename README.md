# ERP Redesign Dashboard Concepts

Three responsive dashboard concepts built with HTML, CSS, and JavaScript.

- **Example 1:** Light glassmorphism CRM dashboard with PDF export
- **Example 2:** Green sales administration dashboard with PDF export
- **Example 3:** Dark analytics dashboard with light mode and subtle animations

Open `index.html`, `example-2/index.html`, or `example-3/index.html` directly in a browser.
